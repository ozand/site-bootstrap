Copied into every new site as `.agents/skills/` by `scripts/create-site.mjs`.

Origin: curated from ai-business-catalyst (2026-08). Rules:

- Skills here must be **portable** — no site-specific paths, data, or brand references.
- Improvements made inside a generated site that generalize → upstream them here.
- Fixes here → propagate to active sites on their next maintenance pass.
