# Technical SEO Skill

## 1. Quick Use
- **When to use:** crawlability, indexation, metadata, sitemap, robots, and structured-data work.
- **How to invoke:** `skill({ name: "technical-seo" })`.
- **Execution pattern:** audit technical signals, remediate by priority, verify crawler-facing output.
- **Definition of done:** critical technical SEO blockers are removed and checks pass.

## 2. Overview
Optimization of technical aspects for Search Engines (Google, Bing) and AI Search Engines (Perplexity, SearchGPT). Focuses on crawlability, indexing, and structured data.

## 3. Key Components

### 3.1. Meta Tags & Head
- **Title:** Unique, descriptive, under 60 chars.
- **Description:** Actionable summary, under 160 chars.
- **Canonical:** Self-referencing URL to prevent duplicate content issues.
- **Open Graph:** `og:image`, `og:title`, `og:description` for social sharing.
- **Robots:** `index, follow` (default) or `noindex` for utility pages.

### 3.2. Structured Data (JSON-LD)
- **Schema.org:** Use strict typing.
- **Article:** For blog posts (`headline`, `image`, `datePublished`, `author`).
- **BreadcrumbList:** For navigation structure.
- **Organization:** For the home page.
- **FAQPage:** For FAQ sections.

### 3.3. Crawlability
- **Sitemap:** `sitemap-index.xml` and sub-sitemaps (auto-generated by Astro).
- **Robots.txt:** Allow bots, disallow private API routes.
- **Links:** Use `<a>` with `href`. Avoid `onclick` navigation.
- **Status Codes:** Ensure 404 for missing pages, 301 for redirects.

### 3.4. Crawler-facing semantic structure
- **H1:** Verify one clear primary heading in rendered output.
- **Outline:** Verify a crawlable hierarchy for page interpretation.
- **Internal links:** Audit that intended links render as crawlable `<a href>` destinations. Route contextual target choice, anchor wording, placement, and insertion to [content-interlinking](../content-interlinking/SKILL.md).

For portfolio-wide prioritization route findings to [seo-mastery](../seo-mastery/SKILL.md); for answerability and evidence structure route to [geo-optimization](../geo-optimization/SKILL.md). Use [skill-portfolio-routing](../skill-portfolio-routing/SKILL.md) when ownership is unclear.

## 4. Checklist
- [ ] `<title>` and `<meta description>` present and unique?
- [ ] Canonical URL set?
- [ ] JSON-LD valid (Test with Rich Results Test)?
- [ ] Sitemap.xml generated and linked in robots.txt?
- [ ] Open Graph image present?
- [ ] 404 page exists and returns 404 status?
